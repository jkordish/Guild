# EPIC-07. Verification Matrix and Verified Catalog

**Status:** Proposed
**Milestone:** M3
**Owner:** TBD
**Last updated:** 2026-03-28

## Objective

Replace vague trust claims with a compatibility and verification system that labels curated and verified packs honestly.

## Why now

If Guild cannot prove why a pack is trusted, it has no durable edge over generic distribution surfaces.

## In scope

- verification matrix
- compatibility report
- verify command
- eval coverage
- curated / verified labels

## Out of scope

- popularity leaderboard games
- ranking by install count alone
- unverifiable trust badges

## Deliverables

- report format
- `guild verify`
- eval runner
- first-party verification reports
- trust labels backed by checks

## Dependencies

- EPIC-06 receipts and EPIC-05 first-party packs

## Risks

- trust theater
- labels that overstate support
- verification that only checks syntax

## Exit criteria

- every curated pack has a verification report
- verified packs have compatibility + eval backing
- labels are explained clearly in docs
