# EPIC-01. Thesis and Narrative Freeze

**Status:** Proposed
**Milestone:** M1
**Owner:** TBD
**Last updated:** 2026-03-28

## Objective

Freeze the product thesis and enforce a consistent public narrative across the site, README, docs, and CLI.

## Why now

Guild cannot afford to keep explaining itself from the inside out. Every later feature depends on a stable story.

## In scope

- north-star statement
- message hierarchy
- homepage / README / CLI rewrite
- copy review checklist

## Out of scope

- schema implementation
- pack build work
- registry work

## Deliverables

- approved one-line and short-form product definitions
- rewritten homepage hero / subhead
- rewritten README opener
- aligned CLI summary text
- message review gate for future PRs

## Dependencies

- none, this is foundational

## Risks

- endless wording churn
- relapsing into substrate-first copy
- trying to describe every feature in the hero

## Exit criteria

- all top-level surfaces use the same narrative order
- trust appears above the fold
- one concrete operational example appears in the first screen of public docs
