# M2. Make Guild Installable and Useful

**Status:** Proposed
**Duration:** 4 to 6 weeks
**Primary epics:** EPIC-03, EPIC-04, EPIC-05

## Goal

Make Guild usable in the real world the same day someone finds it.

## Deliverables

- friendly authoring layer
- compiler to `SKILL.md`
- pack build + export flow
- 4 first-party starter packs
- 6 reference playbooks
- 5-minute first useful run docs

## Demo

Author a small skill, build a pack, export it, install it, run a reference playbook, and show the result.

## Exit criteria

- first-party packs build without hand-editing generated assets
- reference playbooks are runnable end-to-end
- docs show one obvious path from blank repo to useful run

## Not in scope

- public marketplace
- enterprise private registry

## Risks

- schema complexity outruns author experience
- too many low-value packs instead of a few high-value ones

- GR-009 through GR-026
