# M3. Make Guild Trustworthy and Differentiated

**Status:** Proposed
**Duration:** 3 to 4 weeks
**Primary epics:** EPIC-06, EPIC-07

## Goal

Turn Guild from "installable" into "worth trusting." This is the real product moat.

## Deliverables

- receipt schema and receipt emission
- `guild inspect`
- `guild replay`
- approval policy model
- verification matrix
- verification reports for first-party packs
- curated / verified trust labels

## Demo

Run a playbook, inspect the receipt, replay it, and show the verification report for the pack.

## Exit criteria

- every first-party playbook emits replayable evidence
- verification is more than syntax checking
- curated and verified labels have objective backing

## Not in scope

- public ranking games
- growth hacks around install telemetry

## Risks

- labels without meaningful checks
- replay that only works for toy cases

- GR-027 through GR-036
