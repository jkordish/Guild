# M4. Make Guild Adoptable by Teams

**Status:** Proposed
**Duration:** 3 to 4 weeks
**Primary epics:** EPIC-08 plus hardening

## Goal

Make Guild realistic for a team pilot, not just a founder demo.

## Deliverables

- private pack source support
- bundle signing and verification
- run history export
- governance and pilot onboarding docs
- retention / redaction policy hooks

## Demo

Install a private pack, verify its signature, run a playbook, and export an audit summary.

## Exit criteria

- one team can pilot Guild privately
- one security reviewer can assess blast radius and run history
- one manager can review execution summaries without raw operational detail

## Not in scope

- broad public catalog opening
- generalized enterprise platform ambitions

## Risks

- governance bolted on after the fact
- signing added without clear pack provenance story

## Suggested tasks

- GR-037 through GR-040, plus hardening from M3
